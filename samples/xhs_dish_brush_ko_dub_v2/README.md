# 프로세스 2: 텀 제거 + 배속 + 참고영상 스타일 자막 더빙

`samples/xhs_dish_brush_ko_dub/`(프로세스 1)에서 만든 기본 더빙 쇼츠를, 실제 잘 나가는
쇼츠들의 편집 리듬에 맞춰 한 단계 더 다듬은 버전. 같은 소스 영상(중국 주방용품 소개 영상)을
그대로 재사용하되, 아래 4단계를 추가로 적용했다.

## 산출물

- `final_shorts.mp4` — 최종 쇼츠 (1080x1920, 19.8초)
- `hook_banner.png` — 상단 후킹 배너 (프로세스 1과 동일)
- `caption_template.html` — 자막 스타일 템플릿 (검정 텍스트 + 흰 테두리, Pretendard Black
  62px). Playwright로 문장/어절 조각을 이 템플릿에 끼워 넣어 PNG로 렌더링한 뒤 ffmpeg
  overlay로 합성.

## 프로세스 1 대비 추가된 4단계

### 1. TTS 무음 구간 제거
`ffmpeg -af silencedetect=noise=-30dB:d=0.15`로 나레이션 음성의 문장 사이 텀을 전부 찾아내고,
그 구간에 해당하는 영상+음성을 통째로 잘라내는 방식(점프컷)으로 이어붙임. 문장 사이 공백이
없어지면서 훨씬 타이트한 템포가 됨.

### 2. 1.3배속
텀을 제거한 결과물에 영상은 `setpts=PTS/1.3`, 음성은 `atempo=1.3`을 적용해 피치 깨짐 없이
전체 속도를 30% 올림.

### 3. Gemini로 문장 타이밍 정밀 정렬
TTS 결과 음성 파일을 다시 Gemini Files API에 업로드해서, 대본의 각 문장이 몇 초에
시작/끝나는지 정렬시킴. 이 타임스탬프를 1번(텀 제거)·2번(배속) 변환에 그대로 매핑해서
최종 영상 타임라인 기준 자막 타이밍을 계산 — 실제 무음 구간 데이터와 대조해서 경계를 검증함.

### 4. 참고 영상 스타일로 자막을 잛게 끊기
실제 조회수 잘 나오는 쇼츠 레퍼런스 영상 하나를 프레임 단위로 분석한 결과:
- 자막이 문장 전체를 한 번에 보여주지 않고 **2~4어절씩** 끊어서 순차적으로 노출
- 각 조각은 **0.5~1초** 정도만 보여주고 바로 다음 조각으로 전환 (겹침 없이 연속)
- 스타일은 **검정 텍스트 + 흰색 굵은 테두리** (레퍼런스 스크린샷을 픽셀 단위로 측정해서
  폰트 크기/테두리 두께 비율을 그대로 반영)

이 패턴대로 5문장을 22~23개의 짧은 조각으로 나누고, 3번에서 구한 문장 경계 타이밍 안에서
글자수 비례로 각 조각의 타이밍을 배분함.

## 재사용 가능한 부분 (아직 파이프라인 코드로 정식 편입은 안 됨)

- 무음 구간 탐지 → 점프컷 편집 로직 (`ffmpeg silencedetect` 파싱 + 세그먼트 추출/재결합)
- Gemini Files API로 오디오 업로드 후 문장 타임스탬프 정렬 요청하는 패턴
- 문장을 짧은 자막 조각으로 쪼개고 글자수 비례로 타이밍 배분하는 로직
- 자막 스타일을 레퍼런스 스크린샷에서 픽셀 측정해서 역산하는 방법 (텍스트 색상/테두리
  두께/폰트 크기를 스크린샷 해상도 대비 실제 출력 해상도 비율로 환산)

이 4가지 모두 `samples/xhs_dish_brush_ko_dub/README.md`에 적힌 "아직 통합 안 된 부분"
(`gemini_client.py`, TTS 플러그인)에 이어서 `shorts_factory/pipeline/` 정식 모듈로
편입하면 됨.
