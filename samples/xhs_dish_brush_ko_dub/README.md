# 샘플: 중국 숏폼 → 한국어 더빙 쇼츠 (수동 1건 검증)

소스: 샤오홍슈(小红书) 스타일 주방용품(회전솔+세제분출 수세미) 소개 영상 1건을 받아
줌인 크롭 + 상단 후킹 배너 + 한국어 TTS 더빙까지 전 과정을 수동으로 검증한 산출물.
아직 `shorts_factory` 파이프라인 코드에 통합되지 않은 1회성 실험 결과입니다.

## 산출물

- `final_shorts.mp4` — 완성된 쇼츠 (1080x1920, 35.7초)
- `hook_banner.png` — 상단 후킹 배너 (1080x353, #000000 배경)
- `hook_banner.html` — 배너를 만든 Playwright 렌더링 소스 (Pretendard Black 폰트 로컬 경로를
  참조하므로 그대로 재실행은 안 되고, 스타일 참고용)

## 파이프라인 요약

1. **줌인 크롭으로 중국어 자막/워터마크 제거**
   - 원본 720x1280 영상에서 자막(y≈1050-1099)과 워터마크 "@원본계정"(y≈1190-1207)이
     영상 전체에서 고정 위치에 나타나는 것을 프레임 샘플링으로 확인
   - `crop=585:1040:68:0, scale=1080:1920` — 약 23% 줌, 비율 왜곡 없이 최소한의 크롭으로 제거

2. **Gemini API로 실제 영상을 보고 스크립트 작성**
   - Files API로 원본 영상을 업로드 후 `gemini-3.5-flash`에 넘겨 중국어 받아쓰기 +
     쇼츠용 한국어 대본 재구성 + 상단카피(강조어 포함) 생성을 요청
   - 1차 결과가 TTS로 63초가 나와 원본(35.7초)보다 길어서, "30~33초 분량으로 압축"
     재요청 → 최종 대본 33.5초로 수렴

3. **TTS**: ElevenLabs 키는 이 환경 네트워크 정책상 `api.elevenlabs.io`가 막혀 있어 사용 불가.
   대신 동일한 Gemini API 키로 `gemini-2.5-flash-preview-tts`(Kore 보이스) 호출해 한국어 음성 생성.

4. **최종 합성**: ffmpeg로 크롭+스케일된 영상 위에 배너 오버레이, 원본 음성은 한국어 TTS로 완전 교체.

## 원본 중국어 스크립트 (Gemini 받아쓰기)

이거 디자인 좋아! → 세제 분출 회전 롱핸들 브러시 소개 → 헤드를 세우면 주전자/믹서기 안까지
들어가서 바닥까지 닦임 → 철수세미 대비 손/냄비 안 상함, 부스러기 없음 → PET 소재로 세척력은
그대로 유지하며 냄비는 안 상함 → 세제 분출 기능이 제일 편함 → 손잡이 그립감 좋음 → 냄비/그릇/
도마/싱크대 다용도 → 물로 헹구기만 해도 깨끗 → 예쁘고 실용적 → 매일 요리하는 사람에게 추천

## 최종 한국어 대본 (TTS, 33.5초)

1. 이거 디자인 진짜 대박이죠? 세제가 주르륵 나오는 회전식 만능 브러시예요.
2. 버튼만 가볍게 꾹 누르면 세제가 흘러나와서 손 안 대고도 깨끗하게 설거지 끝!
3. 헤드를 일자로 세우면 좁은 텀블러나 깊은 믹서기 안쪽까지 구석구석 닦여요.
4. 스크래치 걱정 없는 특수 소재라 철수세미만큼 시원하고 안전하게 닦입니다.
5. 편안한 그립감에 냄비, 도마, 싱크대 청소까지 다 되니 매일 설거지 필수템이에요!

## 상단 후킹 배너

- Line 1 (흰색): 설거지가 편해지는
- Line 2: 인생 **만능 브러쉬** (강조어 `#FEF501`)
- 스펙: 1080x353px, 배경 #000000, Pretendard Black, 기본 흰색, 강조 #FEF501, 실제 타이핑 텍스트

## 아직 파이프라인에 통합 안 된 부분

- Gemini Files API 업로드 + `generateContent` 호출 → `shorts_factory/integrations/` 에
  `gemini_client.py` 형태로 정식 편입 필요 (현재는 `claude_client.py`만 있음)
- Gemini TTS(`gemini-2.5-flash-preview-tts`) 호출 → `tts_client.py` 플러그인 구현체로 편입 필요
- 자막/워터마크 위치 자동 탐지(현재는 수동 프레임 샘플링) → 자동화하려면 별도 CV 로직 필요

## 업데이트: 크롭 자동 감지 (`shorts_factory/pipeline/subtitle_crop.py`)

위에서 "아직 통합 안 된 부분"으로 남겨뒀던 자막/워터마크 자동 탐지를 실제 코드로 구현했다
(`pipeline/subtitle_crop.py`). "줌인 크롭"(위 1번 항목)은 방법 자체가 바뀐 게 아니라, 크롭
위치를 사람이 프레임을 보고 재던 것을 코드가 자동으로 찾도록 만든 것 — crop-and-rescale로
잘라내고 다시 채우는 핵심 기법은 동일하다.

실전 검증(실제 TikTok 영상 2건)에서 발견한 한계:

- **밝기만으로는 오탐 발생**: 흰 싱크대, 반사되는 수도꼭지처럼 자막이 아닌데도 밝기만 높은
  배경에 걸림 → 한 줄 안에서 밝기가 급격히 바뀌는 지점(edge) 밀도도 같이 체크하도록 수정해서
  해결 (여러 프레임 중 최소값 대신 중앙값을 쓰는 것도 같이 적용, `render.py`의 얼굴 중심
  탐지와 동일한 방식)
- **반투명 워터마크는 여전히 놓칠 수 있음**: 대비가 약한 반투명 텍스트(예: 계정 핸들
  워터마크)는 밝기+edge 기준을 둘 다 통과하기 어려워서 자동 탐지가 못 잡는 경우가 있었다.
  이 경우 실제 프레임을 확대해서 수동으로 위치를 재조정해야 했음 — 자동 탐지 결과를 항상
  크롭 전 미리보기로 먼저 확인하고 넘어가는 걸 권장 (실제로 이 워크플로우 덕분에 놓친
  워터마크를 커밋 전에 잡을 수 있었음)
